## 📌 项目简介

**轻聊**是一款基于 **Electron + Java 25** 前后端分离架构打造的桌面端即时通讯软件。我们不做大而全的臃肿应用，而是专注于**轻量、流畅、可玩性强**的聊天体验。目前仅支持 **Windows 平台**，需要 **Java 25** 运行环境。

> 🎯 定位：一个能聊天、能玩、能上网、还能尝鲜的桌面社交工具。

---

## ✨ 当前已支持功能

### 💬 即时通讯
| 功能 | 说明 |
|---|---|
| **单聊** | 与好友一对一私密对话，消息实时送达 |
| **群聊** | 支持多人群组聊天，畅所欲言 |
| **建群** | 自由创建群组，邀请好友加入 |
| **拉人进群** | 群主/管理员可邀请通讯录好友入群 |
| **群公告** | 群主可设置群公告，重要信息全员可见 |

### 📎 富媒体 & 工具
| 功能 | 说明 |
|---|---|
| **发送图片** | 支持常见格式图片发送，聊天更生动 |
| **发送文件** | 各类文件一键传输，工作娱乐两不误 |
| **内置小工具** | 集成实用小工具，聊天办公无缝切换 |
| **小游戏** | 🎮 目前已上线 **1 款小游戏**，边聊边玩不无聊 |

### 🌐 上网 & 扩展
| 功能 | 说明 |
|---|---|
| **内置浏览器** | 软件内直接上网，无需切换窗口 |
| **第三方开发者入驻**（规划中） | 未来开放平台，开发者可发布工具/游戏/插件 |

### 🛡️ 安全 & 治理
| 功能 | 说明 |
|---|---|
| **举报用户** | 遇到违规用户可一键举报，维护社区环境 |
| **账号封禁申诉** | 被封禁用户可提交申诉，人工复核 |

### 🔐 注册登录
| 功能 | 说明 |
|---|---|
| **手机号注册** | 输入手机号即可注册 |
| **验证码（自动生成）** | ⚠️ 当前为开发阶段，验证码由系统自动生成，**不会真实发送短信**（省成本，懂的都懂 😂） |

## 🏗️ 技术架构

```
┌─────────────────────────────────────────┐
│           前端 (Electron)                │
│   UI渲染 · 聊天界面 · 小游戏 · 内置浏览器  │
│   跨窗口管理 · 本地缓存                  │
└──────────────────┬──────────────────────┘
                   │ HTTP / WebSocket
┌──────────────────▼──────────────────────┐
│           后端 (Java 25)                 │
│   消息分发 · 群组管理 · 用户认证          │
│   举报审核 · 文件存储 · 业务逻辑          │
└─────────────────────────────────────────┘
```

| 层级 | 技术栈 |
|---|---|
| 前端 | Electron（Chromium + Node.js） |
| 后端 | Java 25（最新 LTS 特性） |
| 通信 | HTTP REST + WebSocket 实时推送 |
| 数据库 | 本地 + 服务端双层存储 |
| 运行平台 | **仅 Windows（x64）** |

## 📋 使用须知

| 项目 | 要求 |
|---|---|
| **操作系统** | Windows 7 / 10 / 11（仅限 Windows） |
| **Java 环境** | 必须安装 **Java 25** 并配置环境变量 |
| **手机端** | ❌ 暂不支持，仅限电脑使用 |
| **网络** | 需要互联网连接 |
| **短信验证** | 验证码自动生成，无需真实手机接收 |

> 💡 **安装步骤简述：**
> 1. 安装 Java 25 并确认 `java -version` 输出正确
> 2. 下载轻聊安装包
> 3. 启动后端服务（Java）
> 4. 打开 Electron 客户端，注册登录即可开聊

## ⚠️ 已知限制 & 坦诚说明

| 限制 | 原因 |
|---|---|
| 仅支持 Windows | 开发资源有限，优先打磨单平台体验 |
| 需自行安装 Java 25 | 未做内置 JRE 打包，减小安装包体积 |
| 验证码不真实发送 | 暂无预算接入短信 SDK，先跑通流程 |
| 只有 1 个小游戏 | 开发精力有限，后续持续添加 |
| 无手机端 | 团队规模小，桌面端优先 |

> 我们坦诚面对现状，也真诚邀请你一起参与建设。每一个建议都可能成为下一个版本的功能！
